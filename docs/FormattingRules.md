# Правила оформления пояснительной записки и графической части

## 1. Общие требования к тексту

| Параметр | Требование |
|----------|------------|
| Формат бумаги | А4 (210×297 мм). Для крупных рисунков/таблиц допускается А3 |
| Шрифт | Times New Roman |
| Размер шрифта | 14 пт (основной текст) |
| Межстрочный интервал | 1.5 |
| Заголовки таблиц и подрисуночные надписи | Шрифт 12, интервал 1 |
| Поля листов (рамки) | Левое: 20 мм; Верхнее, Правое, Нижнее: по 5 мм |
| Абзацный отступ | 5 знаков |
| Нумерация страниц | Сквозная, арабскими цифрами, вверху посередине. На титульном листе и задании номер не ставится, но они входят в нумерацию |

## 2. Оформление заголовков

### Разделы
- Печатаются **прописными буквами**, по центру, без точки в конце
- Пример: `1. СПЕЦИАЛЬНАЯ ЧАСТЬ ПРОЕКТА`

### Подразделы и пункты
- С абзаца, строчными буквами (кроме первой), без подчеркивания
- Пример: `1.1. Объект исследования`

### Нумерация
| Уровень | Формат |
|---------|--------|
| Разделы | `1.`, `2.`, `3.`... |
| Подразделы | `1.1.`, `1.2.`... |
| Пункты | `1.1.1.`, `1.1.2.`... |

### Не нумеруются
- Аннотация
- Введение
- Заключение
- Содержание
- Список литературы

### Запрещено
- Переносы слов в заголовках
- Сокращения в заголовках

## 3. Формулы и уравнения

- Нумеруются в пределах раздела (например: `(3.1)` — первая формула третьего раздела)
- Номер у правого края страницы в круглых скобках
- После формулы ставится знак препинания (запятая или точка) до номера формулы
- Расшифровка символов начинается со слова `где` (без двоеточия) с новой строки

### Пример оформления:
```
σ = N / A,                                                                 (1.2)

где σ – нормальное напряжение, Па;
    N – нормальная сила, Н;
    A – площадь поперечного сечения стержня, м².
```

## 4. Иллюстрации (Рисунки)

- Называются «Рис.»
- Нумерация сквозная в пределах раздела (например: `Рис. 4.1`)
- Располагаются после текста, где упомянуты впервые, или на следующей странице
- Подпись располагается снизу

### Форматы подписи:
| Наличие названия | Формат |
|------------------|--------|
| Есть название | `Рис. 1.5. Название рисунка` |
| Нет названия | `Рис. 1.5` (точка после номера не ставится) |

- **На все иллюстрации должны быть ссылки в тексте**

## 5. Таблицы

- Нумерация в пределах раздела (например: `Таблица 2.3`)
- Номер и слово «Таблица» располагаются у правого края над заголовком таблицы
- Заголовок таблицы помещается над её головкой посередине
- Единицы измерения выносятся в заголовок графы или общий заголовок таблицы (не ставятся после чисел)
- При переносе на следующую страницу пишется: `Продолжение таблицы 2.3`

## 6. Список литературы

- Оформление по **ГОСТ 7.1-2003**
- Ссылки в тексте в квадратных скобках: `[4]`
- Порядок расположения: по порядку упоминания в тексте ИЛИ в алфавитном порядке
- Включаются все использованные печатные и рукописные материалы

## 7. Приложения

- Каждое приложение с новой страницы
- Заголовок: `ПРИЛОЖЕНИЕ` (прописными), порядковый номер в правом верхнем углу
- Нумерация рисунков/таблиц в приложениях: `Рис. П.1.3` (третий рисунок первого приложения)

## 8. Графическая часть (Чертежи/Плакат)

- Выполняется по **ГОСТ 2.104-01** и **ГОСТ 2.401-93**
- Шрифт надписей: Times New Roman

### Основная надпись (штамп):
| Лист | Форма штампа |
|------|--------------|
| Первый лист | Форма 1 |
| Последующие листы | Форма 2а |

- **Обозначение документа:** `ПМиИ.07.01.02.ГР` (где ГР — графическая часть)
