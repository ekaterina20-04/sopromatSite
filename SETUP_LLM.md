# Как подключить AI-чат к сайту — инструкция

Весь код уже написан. Тебе нужно выполнить три вещи:
получить ключ OpenAI, установить Docker, запустить проект.

---

## Шаг 1. Получить API-ключ OpenAI

1. Зайди на [platform.openai.com](https://platform.openai.com) и зарегистрируйся
2. В левом меню выбери **API keys** → **Create new secret key**
3. Скопируй ключ — он выглядит как `sk-proj-...` или `sk-...`
   > Ключ показывается **только один раз**. Сразу сохрани его куда-нибудь.
4. Пополни баланс: **Billing → Add payment method**
   Для диплома хватит $5. Модель `gpt-4o-mini` очень дешёвая (~$0.15 за миллион токенов).
5. **Опционально, но рекомендую:** поставь лимит трат
   **Billing → Usage limits → Monthly budget** → поставь $5–10, чтобы случайно не потратить больше.

---

## Шаг 2. Создать файл с ключом

В папке `backend/` создай файл `.env` (без расширения, просто `.env`):

```
OPENAI_API_KEY=sk-...вставь-свой-ключ-сюда...
```

> **Важно:** этот файл уже добавлен в `.gitignore` — он никогда не попадёт в GitHub.
> Никому не отправляй этот файл и не показывай ключ.

Итоговая структура рядом с файлом `.env.example`:
```
backend/
├── .env          ← создаёшь ты (с реальным ключом)
├── .env.example  ← уже есть (шаблон, без ключа)
```

---

## Шаг 3. Установить Docker

Docker — это программа, которая запускает проект в изолированных контейнерах.
Тебе не нужно разбираться как он работает — просто установи.

1. Скачай **Docker Desktop** для Windows:
   [docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/)
2. Установи и перезагрузи компьютер
3. Запусти Docker Desktop — в трее должен появиться значок кита 🐳
4. Убедись, что Docker работает — открой терминал и выполни:
   ```bash
   docker --version
   ```
   Должно вывести что-то вроде `Docker version 27.x.x`

---

## Шаг 4. Запустить проект

Открой терминал в папке `SOPROMAT_SITE` (корень проекта) и выполни:

```bash
docker-compose up --build
```

Первый запуск займёт 3–5 минут — Docker скачает образы и соберёт проект.
При последующих запусках будет быстрее.

Когда увидишь в терминале:
```
frontend-1  | ...nginx...
backend-1   | Backend listening on port 3001
```
— всё готово. Открывай в браузере: **http://localhost**

---

## Шаг 5. Остановить проект

Когда закончишь — нажми `Ctrl+C` в терминале, или выполни:

```bash
docker-compose down
```

---

## Что происходит "под капотом" (кратко)

```
Браузер → nginx (фронтенд-контейнер) → отдаёт твой React-сайт
Браузер → /api/chat → nginx → backend-контейнер → OpenAI API
                                      ↑
                              ключ хранится здесь,
                              пользователь его не видит
```

Ключ никогда не попадает в браузер — это главное требование безопасности
при работе с платными API.

## Частые проблемы

| Проблема | Решение |
|---|---|
| `docker: command not found` | Docker Desktop не установлен или не запущен |
| `port 80 is already in use` | Закрой другой сервер на порту 80, или измени `"80:80"` на `"8080:80"` в `docker-compose.yml` |
| Чат отвечает "ошибка сервера" | Проверь, что в `backend/.env` правильный ключ |
| Чат не отвечает вообще | Посмотри логи: `docker-compose logs backend` |
| Ключ кончились деньги | Пополни баланс на platform.openai.com/billing |

---

## Проверка что всё работает

1. Открой `http://localhost` — сайт должен загрузиться
2. Перейди на страницу **Калькулятор**
3. В правом нижнем углу появится кнопка 💬
4. Нажми на неё и задай вопрос, например: *"Объясни эпюру поперечных сил"*
5. Если AI ответил — всё работает
