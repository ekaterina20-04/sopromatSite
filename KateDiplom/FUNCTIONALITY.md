# SopromatLab — Описание функционала и алгоритмов расчёта

## 1. Общее описание

**SopromatLab** — интерактивная обучающая платформа по основам сопротивления материалов с визуализацией деформаций. Реализована как клиентское React-приложение (TypeScript + Vite) без серверной части. Все расчёты выполняются в браузере.

### Стек технологий
- **React 19** + TypeScript 5.9 + Vite 7.3
- **Chakra UI** — компонентная библиотека
- **Framer Motion** — анимация эпюр
- **D3.js** — доступен для расширения визуализации
- **html2canvas + jsPDF** — экспорт в PDF
- **MathJax** — рендеринг формул в разделе теории

## 2. Поддерживаемые расчётные схемы

### 2.1 Консольная балка (cantilever)
- Защемление у левого конца (x = 0), свободный конец (x = L).
- Граничные условия: v(0) = 0, θ(0) = 0.
- Реакции: вертикальная R_зад и реактивный момент M_зад.

### 2.2 Шарнирно-опёртая балка (simply-supported)
- Шарнирная опора A (x = 0), шарнирная опора B (x = L).
- Граничные условия: v(0) = 0, v(L) = 0.
- Реакции: R_A и R_B.

### 2.3 Балка с вылетом (overhang)
- Опора A (x = 0), опора B (x = L), консольный вылет [L, L+c].
- Граничные условия: v(0) = 0, v(L) = 0.
- Реакции: R_A и R_B (R_A может быть отрицательной при нагрузке на вылете).

### 2.4 Г-образная рама (frame-g)
- Вертикальная стойка высотой H, горизонтальная балка длиной L.
- Защемление у основания стойки (y = 0).
- Параметрическая координата s: [0, H] — стойка, [H, H+L] — балка.
- Учитывает продольную силу N(x) в дополнение к Q(x) и M(x).

## 3. Типы нагрузок

### 3.1 Сосредоточенная сила (PointLoad)
- Параметры: F (Н), позиция a (м), направление (вертикальная/горизонтальная).
- Влияние: скачок Q на величину F, излом M.

### 3.2 Распределённая нагрузка (DistributedLoad)
- **Равномерная** (uniform): постоянная интенсивность w (Н/м) на участке [start, end].
- **Треугольная** (triangular): линейно меняющаяся интенсивность от w₁ до w₂.
- Результирующая сила:
  - Равномерная: F = w · (end − start)
  - Треугольная: F = (w₁ + w₂) / 2 · (end − start)
- Центроид (точка приложения равнодействующей):
  - Равномерная: x_c = (start + end) / 2
  - Треугольная: x_c = start + len · (w₁ + 2·w₂) / [3·(w₁ + w₂)]

### 3.3 Сосредоточенный момент (MomentLoad)
- Параметры: M₀ (Н·м), позиция a (м).
- Влияние: скачок M на величину M₀, Q не меняется.

## 4. Алгоритм расчёта

### 4.1 Определение опорных реакций

**Шарнирно-опёртая балка:**

```
ΣM_B = 0:  R_A · L = Σ[F_i · (L − a_i)]  →  R_A = Σ[F_i · (L − a_i)] / L
ΣF_y = 0:  R_B = ΣF_i − R_A
```

**Консольная балка:**

```
R_зад = ΣF_i               (сумма всех вертикальных сил)
M_зад = Σ(F_i · a_i)       (сумма моментов относительно заделки)
```

**Балка с вылетом:**

```
R_A = Σ[F_i · (L − a_i)] / L    (a_i может быть > L для вылета)
R_B = ΣF_i − R_A
```

### 4.2 Построение эпюр методом сечений

Метод ROSE (Resect – Omit – Substitute – Equilibrate):

1. **Дискретизация**: балка разбивается на 500 равномерных точек: x_k = k · L / (N−1), k = 0..499.

2. **Для каждого сечения x_k** вычисляем Q(x_k) и M(x_k) методом суперпозиции:

**От реакции в опоре A (метод левой части):**
```
Q(x) += R_A
M(x) += R_A · x
```

**От сосредоточенной силы F в точке a (при x ≥ a):**
```
Q(x) −= F
M(x) −= F · (x − a)
```

**От равномерной нагрузки q на [start, end] (при x > start):**
```
x_eff = min(x, end)
len_eff = x_eff − start
dF = q · len_eff
centroid = start + len_eff / 2
Q(x) −= dF
M(x) −= dF · (x − centroid)
```

**От треугольной нагрузки w₁→w₂ на [start, end] (при x > start):**
```
t = len_eff / len
w_x = w₁ + (w₂ − w₁) · t
dF = (w₁ + w_x) / 2 · len_eff
centroid = start + len_eff · (w₁ + 2·w_x) / [3·(w₁ + w_x)]
Q(x) −= dF
M(x) −= dF · (x − centroid)
```

**От сосредоточенного момента M₀ в точке a (при x ≥ a):**
```
M(x) −= M₀
```

### 4.3 Расчёт деформаций (прогибов)

**Дифференциальное уравнение изогнутой оси балки:**
```
EI · v″(x) = M(x)
```

**Двойное численное интегрирование (метод трапеций):**
```
θ(x) = (1/EI) · ∫₀ˣ M(t) dt + C₁      (угол поворота)
v(x) = ∫₀ˣ θ(t) dt + C₂                 (прогиб)
```

**Определение постоянных интегрирования:**

- Консоль: C₁ = 0, C₂ = 0 (из условий v(0) = 0, θ(0) = 0).
- Шарнирно-опёртая: C₂ = 0 (v(0) = 0), C₁ = −v_raw(L) / L (из v(L) = 0).
- Балка с вылетом: C₂ = 0 (v(0) = 0), C₁ = −v_raw(L) / L (из v(L) = 0).
- Г-рама: C₁ = 0, C₂ = 0 (защемление у основания).

**Метод трапеций (trapz):**
```
result[0] = 0
result[i] = result[i−1] + (y[i−1] + y[i]) / 2 · (x[i] − x[i−1])
```

**Максимальный прогиб:**
```
v_max = max|v(x_k)|,  k = 0..499
```

## 5. Верификация по Журавскому

После расчёта автоматически проводится верификация по дифференциальным зависимостям Журавского:

### 5.1 Проверяемые зависимости

```
dQ/dx = −q(x)     — производная Q равна минус интенсивности нагрузки
dM/dx = Q(x)      — производная M равна поперечной силе
d²M/dx² = −q(x)   — вторая производная M равна минус нагрузке
```

### 5.2 Контрольные правила

- Скачок Q(x) в точке сосредоточенной силы F равен F.
- Скачок M(x) в точке сосредоточенного момента M₀ равен M₀.
- Экстремум M(x) достигается в сечении, где Q(x) = 0.

### 5.3 Проверка равновесия

```
ΣF = 0:  |Σ(реакции) − Σ(внешние силы)| < 0.01 · max(|ΣF|, 0.01)
ΣM = 0:  |Σ(реактивные моменты) − Σ(моменты нагрузок)| < 0.01 · max(|ΣM|, 0.01)
```

### 5.4 Численная производная (центральные разности)

```
dy/dx[i] = (y[i+1] − y[i−1]) / (x[i+1] − x[i−1])    для i = 1..N−2
dy/dx[0] = (y[1] − y[0]) / (x[1] − x[0])               крайние точки
```

### 5.5 Нормированная RMS-ошибка

```
RMS = sqrt[ (1/N) · Σ(actual[i] − reference[i])² ] / max|reference|
```

Порог: RMS < 5% — проверка пройдена.

## 6. Визуализация

### 6.1 Расчётная схема (BeamScheme)
- SVG-рисунок 600×160 пикселей.
- Отображает: балку, опоры (шарниры/защемление), нагрузки (стрелки, прямоугольники, символы моментов).
- **Деформированная форма** — наложена пунктиром с цветовой индикацией:
  - Красный (#ef4444) — зоны растяжения (M > 0).
  - Синий (#3b82f6) — зоны сжатия (M < 0).
- **Масштаб деформации**: автоматический (40/max_def) или ручной (ползунок ×1...×500).

### 6.2 Эпюры (DiagramChart)
- SVG-графики 600×140 пикселей для каждой эпюры: M(x), Q(x), N(x).
- Заливка под кривой (15% непрозрачности).
- Нулевая линия (пунктир).
- Симметричная шкала Y (ноль всегда в центре).
- Подсветка точки максимума (кружок).
- **Анимация появления** через Framer Motion (fade + slide, 0.4с).

### 6.3 Интерактивный hover
- При наведении мыши на эпюру отображаются:
  - Текущее значение эпюры в точке.
  - Q(x), M(x) — значения поперечной силы и момента.
  - σ = M · (h/2) / I — нормальное напряжение в крайнем волокне.
- Вертикальная линия-курсор.
- Кружок в точке на кривой.

### 6.4 Формула нормального напряжения

```
σ(x) = M(x) · y_max / I
```

где y_max = h/2 — расстояние от нейтральной оси до крайнего волокна, h — оценочная высота сечения:

```
h ≈ (12 · I)^(1/3)     (из формулы I = b·h³/12 при b ≈ h)
```

## 7. Образовательные модули

### 7.1 Раздел теории (9 разделов)
1. **Расчётные схемы балок** — 4 типа, особенности каждого.
2. **Сосредоточенные нагрузки** — скачки Q, изломы M.
3. **Распределённые нагрузки** — интегрирование, связь Q и M.
4. **Сосредоточенные моменты** — скачки M, отсутствие влияния на Q.
5. **Материалы и модуль упругости** — E, I, жёсткость EI.
6. **Правила знаков** — Q, M, N — определения и типичные ошибки.
7. **Дифференциальные зависимости Журавского** — dQ/dx, dM/dx, контрольные правила.
8. **Типичные ошибки** — систематизация 5 групп ошибок студентов.
9. **Прогибы и угол поворота** — дифуравнение, граничные условия, формулы.

Формулы рендерятся через MathJax (LaTeX). Каждый раздел имеет кнопку «Попробовать в калькуляторе».

### 7.2 Пошаговое решение (StepByStep)
Сворачиваемая панель, показывающая 6 шагов решения:
1. Расчётная схема (тип, параметры, EI).
2. Внешние нагрузки (перечисление).
3. Опорные реакции (формулы и значения).
4. Метод сечений ROSE (алгоритм, разбиение на участки).
5. Характерные значения (Q_max, M_max, v_max).
6. Деформации (дифуравнение, граничные условия, результат).

### 7.3 Контекстные подсказки (21 условие)
Автоматически отображаются при соответствии условия:
- **Физические**: симметрия, Q=0 при max M, параболическая M от q=const.
- **Конструктивные**: смена знака на вылете, осевая сила в рамах.
- **Предупреждения**: нет нагрузок, нагрузка на опоре, большой прогиб, верификация не пройдена, малая жёсткость, высокая нагрузка.

### 7.4 Режим Тренажёр
- Генерация случайных задач (консоль или шарнирно-опёртая балка).
- Параметры: длина L = 3–8 м, 1–2 нагрузки (силы 1–20 кН или q = 2–15 кН/м).
- Студент вводит: R_A (или R_зад), R_B (или M_зад), M_max, Q_max.
- Автоматическая проверка с точностью 5%.
- Цветовая индикация: зелёная рамка — верно, красная — ошибка.
- Подсказка с методом решения.
- Отображение правильных ответов после проверки.

## 9. Экспорт и обмен

### 9.1 Share-ссылка
Конфигурация балки кодируется в base64 и передаётся через URL-параметр `?c=...`. При открытии ссылки конфигурация автоматически восстанавливается.

Формат A4, альбомная ориентация. Содержит:

- Скриншот всех эпюр и схемы (html2canvas → PNG).
- Таблица характерных значений (тип, L, E, I, Q_max, M_max, v_max).
- Реакции опор.
- Результат верификации по Журавскому (статус, RMS-ошибка, невязки).

## 11. Формулы-справочник

### Максимальные прогибы (аналитические)

**Консоль, сила на конце:**
```
v_max = F · L³ / (3 · EI)
```

**Шарнирно-опёртая, центральная сила:**
```
v_max = F · L³ / (48 · EI)
```

**Шарнирно-опёртая, равномерная нагрузка:**
```
v_max = 5 · q · L⁴ / (384 · EI)
```

### Реакции опор

**Шарнирно-опёртая, одна сила F в точке a:**
```
R_A = F · (L − a) / L
R_B = F · a / L
```

**Шарнирно-опёртая, момент M₀:**
```
R_A = M₀ / L
R_B = −M₀ / L
```

### Дифференциальные зависимости

```
dN/dz = −q_z        (продольная нагрузка)
dQ/dz = −q_y        (поперечная нагрузка)
dM/dz = Q           (связь момента и Q)
d²M/dz² = −q_y      (связь момента и нагрузки)
```

### Нормальное напряжение в изгибаемой балке

```
σ(x, y) = M(x) · y / I
σ_max = M · y_max / I = M · h / (2 · I)
```
